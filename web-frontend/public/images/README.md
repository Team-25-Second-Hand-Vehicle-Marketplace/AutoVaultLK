# Design photos

Put JPG files here using the exact names below. Until a file exists, the page
shows a labelled placeholder in its place, so you can see the whole layout first.
The full list with sizes and briefs lives in `src/assets/image-slots.ts`.

Real, natural photos are fine. The design does not need studio shots, white
backgrounds or 3D renders. Dark, moody lighting suits the hero images best.
