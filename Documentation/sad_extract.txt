1.2  Scope  
The  “Second  Hand  Vehicle  Marketplace  with  Intelligent  Search  and  Automated  Inventory  Processing”  
web
 
application
 
on

cloud
 
allows

as
  Confidential  ©AutoVault  LK,  2026  Page  7  of  35

The  main  goal  of  the  system  is  to  automate  the  inventory  processing  process  for  vehicle  dealers,  who

The  ETL  pipeline  performs  the  following  operations:  
●  Slicing  large  inventory  files  into  manageable  chunks  for  parallel  processing.  
●  Validation  of  uploaded  vehicle  records  with  row-level  rejection  capabilities.  
●  Data  normalization  to  maintain  consistent  information,  utilizing  a  deterministic  rule-based  
parser
 
with

Groq
 
AI

●  Image  extraction,  resizing,  compression  and  optimization  via  Sharp.  
●  Generation  of  semantic  vector  embeddings  for  intelligent  search  using  a  locally  hosted  
all-MiniLM-L6-v2
 
model.
 
●  Storage  of  processed  vehicle  information  in  PostgreSQL,  utilizing  JSONB  attributes  to  handle  
polymorphic
 
vehicle
 
specifications
 
(e.g.,
 
varying
 
fields
 
for
 
CAR,
 
BIKE,
 
VAN).
 
●  Notification  of  upload  completion,  including  aggregate  success  and  rejection  statistics,  
through
 
email.
 
The  solution  also  offers  intelligent  marketplaces  for  buyers  through  the  combination  of  filter-based  
search
 
and

Buyers

parse

and

Groq
 
AI

PostgreSQL

using
 
pgvector

The  application  supports  three  primary  user  roles:  
●  Buyer  –  Searches  vehicles,  views  vehicle  details  and  manages  favourite  listings.  
●  Dealer  –  Uploads  inventories,  manages  vehicle  listings,  monitors  upload  jobs  and  receives  
notifications.
 
●  Administrator  –  Monitors  system  activities,  manages  users,  reviews  upload  jobs,  maintains

●  Database:  PostgreSQL  with  the  pgvector  extension

Definitions,
 
Acronyms,
 
and
 
Abbreviations
 
Term  Definition  
ETL  
Extract,  Transform,  Load  -  the  automated  pipeline  that  ingests,  validates,  and  stores  dealer-uploaded  vehicle  data.  
JWT  JSON  Web  Token  -  a  signed  token  used  for  stateless  authentication.  
RBAC  
Role-Based  Access  Control  -  authorization  model  restricting  actions  by  user  role  (Guest,  Buyer,  Dealer,  Admin).  
S3  
Amazon  Simple  Storage  Service  -  object  storage  used  for  uploaded  files  and  vehicle  images.  
SQS  
Amazon  Simple  Queue  Service  -  managed  message  queue  used  to  decouple  upload  requests  from  ETL  processing.  
SES  
Amazon  Simple  Email  Service  -  used  to  send  upload  status  notification  emails.  
RDS  
Amazon  Relational  Database  Service  -  managed  hosting  for  the  PostgreSQL  database.  
pgvector  
PostgreSQL  extension  enabling  storage  and  similarity  search  over  vector  embeddings.  
pg_trgm  PostgreSQL  extension  enabling  trigram-based  fuzzy  text  matching.  
NL  search  
Natural-language  search  -  free-text  queries  such  as  "automatic  SUV  under  20  million  LKR".

Dead-letter  queue  -  where  messages  are  routed  after  repeated  processing  failures.  
Lambda  
AWS  Lambda  -  the  serverless  compute  service  that  executes  each  microservice's  containerized  handlers.  
ECR  
Amazon  Elastic  Container  Registry  -  stores  the  Docker  images  deployed  to  Lambda.  
IAM  AWS  Identity  and  Access  Management  -  controls  per-service  permissions.

Continuous  Integration  /  Continuous  Deployment  -  automated  build,  test,  and  deployment  pipeline.

Minimum  Viable  Product  -  the  first  deployable  version  covering  core  scope  only.

2.2  Product  Functions  
•  Dealer  registration,  login  and  profile/approval  management.  
•  Bulk  inventory  upload  via  CSV/JSON  plus  ZIP  image  archives.  
•  Automated  ETL  pipeline:  validation,  normalization,  image  processing,  embedding  generation  
•  Upload  job  status  tracking  and  per-record  error  reporting  for  dealers.  
•  Filter-based  and  natural-language  (hybrid  semantic)  vehicle  search  for  registered  buyers  and

•  Buyer  favourites  and  vehicle  detail  browsing.  
•  Automated  email  notification  of  upload  completion  or  failure.  
•  Administrative  monitoring  of  users,  uploads,  audit  logs  and  platform  reports.  
•  Synthetic  vehicle  data  generation  tool  to  support  testing  without  needing  real  dealer  data.

 Confidential  ©AutoVault  LK,  2026  Page  12  of  35

Administrator  
Platform  operator  with  higher  technical  familiarity;  expected  to  understand  user  management,  audit  logs  and  basic  system  health  indicators.
